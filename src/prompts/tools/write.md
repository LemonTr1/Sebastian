## Write

> 此工具需要用户确认后方可执行。

Create a new file or completely overwrite an existing one. Requires user confirmation.

- Content is written verbatim; existing content is replaced, never appended.
- Prefer `Edit` for changing part of an existing file.
- The parent directory must already exist; create missing directories with `bash` (`mkdir -p`) first.
- PDF/DOCX are not supported.
