## Edit

> 此工具需要用户确认后方可执行。

Replace an exact string in a text file. Requires user confirmation.

- `old_text` must match the file exactly (including whitespace and indentation).
- By default the match must be unique; if multiple matches exist the call fails. Add surrounding context or set `replace_all=true`.
- Read the file first and copy the exact text you want to replace.
- PDF/DOCX/PPTX are not supported.
